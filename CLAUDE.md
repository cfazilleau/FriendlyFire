### Quick Reference Commands
- **Activate Virtual Env**: `.venv\Scripts\activate` (Windows) or `source .venv/bin/activate` (Unix)
- **Install Dependencies**: `pip install -r requirements.txt`
- **Run the Bot**: `python -u main.py`
- **Verify Syntax**: `python -m py_compile <path-to-file>`

For git branch naming, target branches (`unstable`), and detailed database/cog architecture, please refer to **[DEVELOPMENT.md](DEVELOPMENT.md)**.
